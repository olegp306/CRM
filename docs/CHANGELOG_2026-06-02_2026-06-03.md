# Changelog: 2026-06-02 to 2026-06-03

## Version 0.4.3

### Telegram and CRM Orchestrator

- Telegram lead create/update replies now include an `Undo` action.
- Undo for a newly created lead removes or archives the lead and clears linked lead context/calendar rows.
- Undo for a lead update restores the previous lead fields.
- After undoing an update, Telegram can offer `Create new lead from this source` when the same source material should become a separate lead.
- Typed lead undo requests now ask for clarification instead of guessing and accidentally changing CRM data.

### CRM Entity Extraction

- Telegram and Web Assistant messages can extract CRM facts, follow-ups, people, organizations, events, tags, and future actions.
- Extracted CRM context is saved on lead cards.
- Future actions can be surfaced as calendar/action context for a lead.
- Lead names are generated from client/project context and kept compact for Telegram, cards, and search results.

### Lead Search

- Telegram search understands human phrases for project names, client names, tags, locations, and recent lead lists.
- Search results return readable CRM buttons and filtered CRM result links.

### Web App

- The web app version marker opens concise release notes.
- Lead cards show localized names, summary/context sections, and action calendar context.
- Settings lead reset clears linked context/calendar data before deleting test leads.

### Verification

- Telegram worker integration tests cover lead creation undo, lead update undo, recreate-from-source after undo, explicit update commands, and typed undo clarification.
- Current Telegram worker test suite passes with 69 tests.
