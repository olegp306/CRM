# Инструкция пользователя: Telegram и CRM-лиды

Эта инструкция описывает текущий рабочий сценарий: как создать лида из Telegram, как найти существующего лида, как редактировать его через reply, как ставить напоминания, как работать с файлами и как проверять результат в веб-CRM.

Главное правило: **сначала создать или найти лида, потом делать изменения reply-сообщением на карточку этого лида**. Один reply лучше использовать для одного конкретного действия.

## 1. Как устроен Telegram-бот

Входящее сообщение сначала попадает в **CRM Orchestrator**. Он читает сообщение человеческим языком и решает, что нужно сделать:

- создать нового лида;
- найти лида;
- обновить существующего лида через reply;
- сохранить заметку или дополнительный контекст;
- поставить follow-up или напоминание;
- попросить уточнение, если уверенности недостаточно.

После этого CRM Orchestrator передает задачу специализированным частям системы: разбору материалов, обновлению лида, поиску, календарю или извлечению CRM-сущностей.

В настройках есть отдельный контекст **AI people context**. Там описаны внутренние люди проекта, например Олег и Екатерина/Катя. Это нужно, чтобы система не принимала автора скриншота, владельца чата или тестировщика за клиента.

## 2. Команды в меню бота

В Telegram-меню бота доступны две основные команды:

```text
new lead
```

```text
search lead
```

`new lead` включает сценарий создания нового лида. После этого можно присылать текст, PDF, фото, скриншоты, аудио или несколько материалов подряд.

`search lead` включает сценарий поиска. Бот показывает последние лиды и позволяет искать по названию, имени клиента, адресу, тегам, телефону, email и похожим формулировкам.

Старый свободный режим тоже может работать, но для боевого использования надежнее явно выбрать `new lead` или `search lead`.

## 3. Создание нового лида

1. Выберите в меню Telegram команду `new lead`.
2. Отправьте материалы по заявке.
3. Дождитесь ответа с номером лида.
4. Проверьте summary, недостающие поля и кнопки `CRM`, `КП PDF`, `КП DOC`.

Можно отправлять:

- текст;
- голосовое сообщение;
- фото;
- скриншот;
- PDF;
- несколько файлов подряд;
- файл плюс пояснение текстом.

> [!TIP]
> Хороший пример для создания лида:
>
> ```text
> Новый клиент: Ирина Шнайдер, irina@example.com, +49 160 4442211.
> Нужен Neubau EFH в Bad Aibling, Gartenweg 9.
> BGF 195 м2, старт сентябрь 2026, въехать хотят летом 2027.
> Бюджет на архитектурные услуги около 32 000 EUR.
> ```

После создания бот должен показать:

- номер лида;
- короткое summary;
- статус;
- готовность полей для КП;
- тип запроса;
- температуру;
- адрес проекта;
- BGF;
- недостающие поля;
- кнопки `CRM`, `КП PDF`, `КП DOC`, если документы доступны.

## 4. Данные, полезные для коммерческого предложения

Чем больше этих данных есть во входящих материалах, тем быстрее система подготовит КП:

| Что нужно | Как можно назвать |
| --- | --- |
| Имя клиента | клиент, заказчик, contact, client name |
| Email | email, почта, e-mail |
| Телефон | phone, телефон, mobile, WhatsApp |
| Тип запроса | Neubau EFH, Umbau, Sanierung, консультация, feasibility, LP1-4 |
| Адрес проекта | адрес участка, project address, объект, участок, локация |
| BGF | BGF, площадь, gross floor area, м2, sqm |
| Бюджет | budget, бюджет, Honorar, стоимость услуг |
| Желаемый старт | desired start, старт, начать когда |
| Желаемый въезд | desired move-in, въехать когда, дедлайн |
| Стандартность | standard, нестандарт, special case, manual pricing |

Если данных не хватает, бот должен прямо написать, какие поля отсутствуют.

## 5. Поиск лида

Выберите в меню команду:

```text
search lead
```

После входа в режим поиска можно написать:

> [!TIP]
> Хорошие примеры поиска:
>
> ```text
> покажи последние 10 лидов
> ```
>
> ```text
> найди Schneider Bad Aibling
> ```
>
> ```text
> найди лид по Gartenweg
> ```
>
> ```text
> покажи лид по телефону +49 160 4442211
> ```
>
> ```text
> найди проект Neubau EFH в Мюнхене
> ```

Бот показывает список найденных лидов. Кнопки с номерами лидов открывают карточку лида прямо в Telegram. После этого можно сделать reply на карточку и внести изменение, заметку или напоминание.

Кнопка `Open results in CRM` открывает результаты поиска в веб-CRM.

## 6. Редактирование лида через reply

Чтобы изменить лида:

1. Найдите лида через `search lead` или используйте карточку, созданную после `new lead`.
2. Откройте карточку лида в Telegram.
3. Сделайте reply на эту карточку.
4. Напишите одно конкретное действие.

> [!TIP]
> Хорошие reply-примеры:
>
> ```text
> Обнови телефон: +49 170 1234567
> ```
>
> ```text
> Возьми BGF со скрина: 240 м2
> ```
>
> ```text
> Измени адрес проекта на Gartenweg 9, Bad Aibling
> ```
>
> ```text
> Поставь канал связи WhatsApp
> ```
>
> ```text
> Переименуй проект в Schneider EFH Bad Aibling
> ```

Если к reply приложен скриншот, PDF или фото, добавьте короткую подпись, что именно нужно взять из материала.

> [!TIP]
> Хорошие подписи к файлам:
>
> ```text
> Возьми со скрина только телефон клиента.
> ```
>
> ```text
> Возьми со скрина BGF.
> ```
>
> ```text
> Из этого PDF возьми адрес участка.
> ```
>
> ```text
> Из этого сообщения возьми имя проекта и тип проекта.
> ```
>
> ```text
> Это новый материал по этому же лиду, сохрани summary в историю.
> ```

Не стоит в одном reply писать сразу много действий. Надежнее отправить несколько отдельных reply-сообщений.

## 7. Какие поля можно обновлять

Сейчас надежнее всего обновлять такие поля:

| Поле CRM | Пользовательские слова и алиасы |
| --- | --- |
| `clientName` | имя клиента, заказчик, клиент, client |
| `email` | email, почта, e-mail |
| `phone` | телефон, номер, mobile, WhatsApp number |
| `requestType` | тип проекта, тип запроса, что нужно, request, услуга, scope |
| `projectAddress` | адрес, адрес объекта, участок, project address, site address |
| `bgfM2` | BGF, площадь, м2, sqm, gross floor area |
| `budgetEur` | бюджет, budget, стоимость, Honorar |
| `desiredStart` | старт, дата старта, когда начать, desired start |
| `desiredMoveIn` | въезд, дедлайн, move-in |
| `displayName` | название лида, имя проекта, project title, lead title |
| `source / rawInput` | исходные материалы, дополнительный файл, скрин, PDF, аудио |

## 8. Заметки и дополнительная информация

Если нужно просто сохранить факт, который не является отдельным CRM-полем, сделайте reply на карточку лида и явно напишите, что это заметка или дополнительная информация.

> [!TIP]
> Хорошие примеры:
>
> ```text
> Добавь заметку: сегодня встречались за кофе, клиент любит джаз.
> ```
>
> ```text
> Запомни об этом клиенте: общаться лучше через WhatsApp.
> ```
>
> ```text
> Дополнительная информация: пришел через Евгена.
> ```
>
> ```text
> Комментарий: клиент просил не звонить утром.
> ```
>
> ```text
> Сохрани в историю: КП обсудили, клиент попросил вернуться через неделю.
> ```

Такая информация попадает в историю лида и помогает позже понимать контекст.

## 9. Напоминания и follow-up

Чтобы поставить напоминание, сделайте reply на карточку лида и напишите одно действие с датой или временем.

> [!TIP]
> Хорошие примеры:
>
> ```text
> Напомни завтра позвонить клиенту по КП.
> ```
>
> ```text
> Поставь напоминание через 5 дней проверить, ответил ли клиент.
> ```
>
> ```text
> На следующий вторник запланируй follow-up по документам.
> ```
>
> ```text
> Напомни в пятницу в 10:00 написать клиенту по WhatsApp.
> ```
>
> ```text
> Через две недели спроси, получил ли клиент коммерческое предложение.
> ```
>
> ```text
> Если клиент не ответит до понедельника, напомни сделать follow-up.
> ```
>
> ```text
> Поставь задачу на 15 июня: уточнить решение по LP1-4.
> ```
>
> ```text
> Раз в год 14 июня напоминать поздравить с днем рождения.
> ```

Если даты нет, ассистент должен попросить уточнить дату.

Плохо:

```text
Надо потом как-нибудь связаться.
```

Лучше:

```text
Напомни в пятницу в 10:00 написать клиенту по WhatsApp.
```

## 10. Скриншоты, PDF, фото и аудио

Система умеет принимать source materials:

- фото участка;
- скриншоты переписки;
- PDF;
- голосовые сообщения;
- несколько файлов подряд.

Если это новый лид, начните с `new lead`.

Если это дополнение к существующему лиду, сначала найдите лида через `search lead`, откройте карточку в Telegram и сделайте reply на карточку.

> [!TIP]
> Хороший кейс с материалами:
>
> ```text
> Это новый скрин по этому лиду. Отсюда нужно взять тип проекта и адрес участка.
> ```
>
> Потом отдельным reply:
>
> ```text
> Возьми со скрина номер телефона клиента.
> ```
>
> Потом отдельным reply:
>
> ```text
> Дополнительная информация: канал связи WhatsApp, пришел через Евгена.
> ```

Почему так лучше: первое сообщение обновляет поля, второе обновляет телефон, третье сохраняет контекст в историю. Система меньше рискует смешать несколько действий.

## 11. Веб-CRM и карточка лида

В Telegram-сообщениях обычно есть кнопка:

```text
CRM
```

Она открывает карточку лида в веб-CRM.

В карточке можно увидеть:

- номер и название лида;
- температуру;
- тип запроса;
- адрес;
- BGF;
- бюджет;
- недостающие поля;
- ближайшее календарное действие;
- lead summary info;
- CRM-контекст;
- history;
- action plan;
- source materials;
- кнопки `KP PDF` / `KP DOC`, если КП сформировано.

В веб-CRM данные можно редактировать через форму карточки лида. Если после множества правок summary устарело, используйте кнопку:

```text
Refresh summary
```

Она пересобирает summary по текущим данным лида и исходным материалам.

## 12. Что делать, если ассистент ошибся

Если ассистент создал нового лида, хотя должен был обновить старого, или наоборот, используйте `Undo`, если кнопка доступна в Telegram-ответе.

После undo можно явно написать:

```text
Это был новый лид, создай отдельную карточку из этих данных.
```

Или:

```text
Это было дополнение к существующему лиду, обнови его.
```

Если ассистент не уверен, он должен задать уточняющий вопрос. Это нормальное поведение.

## 13. Рекомендуемый процесс

1. Выберите `new lead`.
2. Отправьте исходные материалы.
3. Дождитесь номера лида.
4. Проверьте summary и недостающие поля.
5. Если нужно добавить данные, сделайте reply на карточку лида одним конкретным действием.
6. Если нужно найти старого лида, выберите `search lead`.
7. После поиска откройте карточку лида в Telegram.
8. Reply на карточку для изменения, заметки или напоминания.
9. Откройте `CRM`, чтобы проверить карточку в вебе.
10. Когда данных достаточно, откройте или скачайте `КП PDF` / `КП DOC`.

## 14. Мини-шпаргалка

Создать лида:

```text
new lead
```

Найти лида:

```text
search lead
```

Обновить поле:

```text
Reply на карточку: Обнови BGF: 240 м2
```

Добавить заметку:

```text
Reply на карточку: Дополнительная информация: клиент пришел через Евгена.
```

Поставить напоминание:

```text
Reply на карточку: Напомни завтра написать клиенту по WhatsApp.
```

Приложить новый материал к существующему лиду:

```text
Reply на карточку + файл: Это скрин по этому лиду, возьми отсюда телефон.
```

Безопасное правило:

```text
Один reply = одно действие.
```
