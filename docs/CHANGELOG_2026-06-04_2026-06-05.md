## 0.4.25 Lead Table And Client Linking Release

- Lead tables now default to client, project, area, description, interest, urgency, todo, address, phone, email, messenger, source, and client-project-count columns.
- Column visibility, widths, and column order are saved in table preferences.
- Table headers can be reordered with drag handles, and column widths can be resized.
- The lead table includes full and inline modes, with inline editing for safe lead fields and linked-client contact fields.
- Lead cards use the same leading field order as the default table, then show the remaining editable fields.
- Lead cards include a confirmed delete action that removes the lead and linked context/calendar rows.
- Telegram and web lead creation now link to an existing matching client, or create and link a client when enough contact data is available.

## Telegram Routing, Undo, And Reminder Reliability

- Telegram now treats menu `/newlead` as a hard new-lead command and `/searchlead` as a search command.
- Natural phrases such as "next client", "new client", and Russian equivalents are treated as fresh lead creation even when a previous Telegram lead session is active.
- Replies to a lead card are handled as lead-specific update, note, reminder, or source-material actions instead of restarting search mode.
- Telegram lead update undo restores the previous lead state, including display name, after accidental merges.
- Reply-based reminders are stored as separate CRM calendar actions so multiple reminders accumulate instead of replacing each other.
- Reminder parsing guidance covers natural Russian relative dates such as "через N дней", Russian word numbers, next-week weekdays, and morning/lunch/evening defaults.

## Orchestrator Prompt Merge

- The CRM orchestrator default prompt now uses one clean markdown source shared with the documented settings prompt.
- The merged prompt keeps support/search/reply-routing guidance from test and adds newer Telegram next-client and reminder-date rules.
- The prompt explicitly separates lead creation, lead update, lead search, reminder, and support routing.
